# Motorcycle Crash Severity Analysis Code

Code accompanying the study **“Motorcycle Crash Severity Prediction under Temporal Validation with Leakage-Controlled Machine Learning and SHAP Interaction Analysis.”**

## Files

- `src/motorcycle_crash_pipeline.py` — main analysis pipeline
- `src/supplementary_analyses.py` — supplementary analyses
- `src/shap_analysis.py` — SHAP main-effect, interaction, and stability analyses
- `requirements.txt` — Python dependencies
- `run_all.bat` — Windows launcher

## Setup

```bash
pip install -r requirements.txt
```

The dataset is not included in this repository.
